TextAssignment file organization

Part_A
- data
  - Data_1.txt: used for tokenization, filtering, stemming, and Q5.
  - Data_2.txt: used for POS tagging and syntactic analysis.
  - Data_3.txt: used for sentence probability calculations.
- Q2_Word_Stemming
  - WordStemming.py: Regular Expression, Porter, and Lancaster stemming.
- Q4_Sentence_Probabilities
  - SentenceProbabilities.py: unsmoothed and smoothed bigram sentence probabilities.
- Q5_Alternative_Tokenization
  - Q5_Christabel.py: CountVectorizer alternative tokenization.
  - Q5_Joshua.py: SpaCy alternative tokenization.
  - Q5_Yingxin.py: TextBlob alternative tokenization.

Part_B
- data
  - cyberbullying_tweets.csv: original raw dataset.
  - cyberbullying_clean.csv: cleaned dataset used by the models.
- Q1_Dataset_EDA
  - Q1_EDA.py: dataset overview, preprocessing, and EDA.
  - CleanData.py: simpler cleaning-only script.
- Q2_Supervised_Classification
  - LRModelQ2.py: Logistic Regression model.
  - RFModelQ2.py: Random Forest model.
  - SVMModelQ2.py: Linear SVM model.
- Q3_Hyperparameter_Selection
  - LRModelQ3.py: Logistic Regression tuning.
  - RFModelQ3.py: Random Forest tuning.
  - SVMModelQ3.py: Linear SVM tuning.
- Q4_Model_Evaluation
  - LRModelEva.py: tuned Logistic Regression evaluation.
  - RFModelEva.py: tuned Random Forest evaluation.
  - SVMModelEva.py: tuned Linear SVM evaluation.
- models
  - Saved .joblib model files generated by Q2 and Q3 scripts.

Suggested run order
1. python Part_B\Q1_Dataset_EDA\Q1_EDA.py
2. python Part_B\Q2_Supervised_Classification\SVMModelQ2.py
3. python Part_B\Q3_Hyperparameter_Selection\SVMModelQ3.py
4. python Part_B\Q4_Model_Evaluation\SVMModelEva.py
